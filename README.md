# Onboarded HTML Copy

A responsive, single-file HTML reproduction inspired by the public Onboarded website. Built with plain HTML, CSS, and JavaScript—no build tools or dependencies required.

## Preview locally

Open `index.html` in a modern browser, or serve this folder with any static web server.

## Publish with GitHub Pages

1. Open this repository's **Settings**.
2. Select **Pages** from the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. The URL will appear in the Pages settings.

## What's included

- Responsive desktop and mobile layouts
- Mobile navigation menu
- FAQ accordions
- Inline CSS, simple JavaScript, and dashboard mockup
- Links to the official Onboarded website for authoritative product information
